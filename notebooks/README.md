# Notebooks Directory

This directory contains Jupyter notebooks for:

- **eda-fraud-data.ipynb**: Exploratory Data Analysis for fraud detection dataset
- **eda-creditcard.ipynb**: Exploratory Data Analysis for credit card dataset
- **feature-engineering.ipynb**: Feature engineering and data preparation
- **modeling.ipynb**: Model training and evaluation
- **shap-explainability.ipynb**: SHAP-based model explainability analysis
